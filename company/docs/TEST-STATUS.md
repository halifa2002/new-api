## 二、冒烟脚本为什么跑不完

**现象**：脚本打印完标题、最多两项检查后，**静默退出，退出码 0**，没有报错信息。

**已定位到最小复现**：脚本里有个内部函数 `Invoke-Api`，只要调用它，进程就在函数内部静默结束：

```
A-start          ← 打印到这
（然后什么都没有，exit 0）
```

把同一段请求换成脚本外的 `Invoke-WebRequest` 直接调用，一切正常（HTTP 200、字段齐全）。所以问题在**这个函数在当前环境（Windows PowerShell 5.1 / Windows 11 build 26200）下的行为**，不是网络、不是后端。

排除过的方向：

- 不是后端不可达（同一时刻 `/api/status` 用 curl 与 `Invoke-WebRequest` 都正常）
- 不是登录限流（重启容器清空计数器后现象不变）
- 不是参数绑定（`-BaseUrl` 已正确传入，标题行里打印出来了）
- 不是编码问题（文件本身带 BOM，前两行中文正常输出）

**结论**：这是一个待查的脚本/环境兼容问题，不是产品缺陷。

## 四、要补这一项，怎么做

1. 先修 `smoke-test.ps1` 里的 `Invoke-Api`（可选：直接改用 `Invoke-WebRequest`，去掉这层封装）
2. 或按冒烟脚本第 6~8 项的逻辑，手工走一遍：建 Key → 调一次 `deepseek-flash` → 比对 `/api/user/self` 的 `quota` 是否减少
3. 跑之前先把登录限流放一放（同一 IP 连续登录过多会 429；本地没有 Redis，**重启容器即可清空**）

## 五、其他已知限制

- 验收测试 #5「请求超时」：本机响应太快，1 秒超时触发不了，只验证了「客户端中断后服务存活」；真实超时需构造慢上游
- 验收测试 #6「上游报错」：请求不存在的模型返回 **503 且响应体为空**，脚本按 4xx/503 判过
- 契约测试的数组断言：Windows PowerShell 5.1 的 `ConvertFrom-Json` 会把单元素数组拆成标量，`enable_groups` 这类字段改用「数组或字符串」判定
