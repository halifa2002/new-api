# @portal/ui

品牌官网与用户控制台共用的界面零件。

## 为什么有这一层

领导文档 3.2 要求前端仓库里有统一的 `ui` 组件包。官网和控制台是两个独立的 Next.js 应用，
但「复制按钮」「空状态」「加载骨架」这类零件长得一样，放这里只维护一份。

## 现有组件

| 组件 | 用途 |
| --- | --- |
| `CopyButton` | 复制文本，1.5 秒后提示「已复制」。官网的代码示例、控制台的 API Key 都用它 |

## 约定

- 只放**与业务无关**的零件。带接口调用、带路由跳转的组件放各自 app 里。
- 样式只用设计变量（`design-tokens` 里的 `text-ink-muted`、`border-line` 等），不写死颜色。
- 新增组件时补一行到上表，并在 `src/index.ts` 导出。
