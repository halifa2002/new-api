# docs（前端开发者文档）

面向改前端的人的说明。项目级文档（审计报告、接口清单、数据库结构、部署与回滚手册）统一放在仓库根的 `company/docs/`，不在这里重复。

## 改前端前先看

1. `company/ARCHITECTURE.md`：三块界面怎么分工、请求怎么走
2. `company/DEPLOY.md`：本地怎么起、上线怎么发
3. 各应用的 `README.md`：页面清单与目录约定

## 这里以后放什么

- 新页面接哪个接口、需要什么权限
- 前端约定（命名、状态管理、错误提示的写法）
- 常见问题的排查步骤

现在这些内容还散在 `company/ARCHITECTURE.md` 和代码注释里，等写新页面时再逐步挪过来。
